## Описание работы программы: 
Программа преобразует цвета из RGB в XYZ в HLS по цепочке (в обе стороны), 
а так же даёт возможность выбрать цвет на палире (цвет выбирается в HEX, затем преобразуется в RGB и далее по цепочке)
